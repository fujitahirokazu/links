プライバシーポリシー

アプリ名: 明日使える名著 メディア自動化（YouTube アップローダー）／最終更新: 2026-07-13

1. 概要

本アプリは、運営者本人が管理するYouTubeチャンネル（@fujita.meicho）に、本人が作成した動画コンテンツをアップロードおよび公開予約するためだけに使用する、個人運用のツールです。第三者のユーザーを対象としたサービスではありません。

2. YouTube API サービスの利用

本アプリは YouTube API サービス を利用します。利用にあたっては YouTube 利用規約 および YouTube API Services Terms of Service が適用されます。Google によるユーザー情報の取り扱いについては Google プライバシーポリシー（https://policies.google.com/privacy） をご参照ください。

3. アクセスする情報とスコープ

本アプリは Google OAuth 2.0 を通じて、以下の YouTube Data API スコープにアクセスします。

  • https://www.googleapis.com/auth/youtube.upload — 本人チャンネルへの動画アップロード
  • https://www.googleapis.com/auth/youtube.force-ssl — アップロード済み動画の公開予約（publishAt）・メタデータ更新

アクセスするのは認可した本人アカウントのYouTubeデータのみで、他ユーザーのデータや、YouTube以外の個人情報（連絡先・位置情報等）は取得しません。

4. 情報の利用目的

取得したアクセストークンおよびAPIアクセスは、本人が用意した動画ファイルとメタデータ（タイトル・説明・タグ・公開日時）を本人チャンネルにアップロード／公開予約する目的にのみ利用します。

5. 情報の保存・共有・削除（データ削除ポリシー）

OAuthトークンは運営者本人が管理する環境（ローカルPCおよびGitHub Secrets）にのみ保存し、第三者に共有・販売・譲渡しません。取得したデータを用いた広告・プロファイリング・二次利用は行いません。YouTube API から取得した公開統計データを保存する場合は、YouTube API Services のデベロッパーポリシーに従い、原則として30日以内に削除します。運営者は Google アカウントのセキュリティ設定（アカウントにアクセスできるアプリ） からいつでも本アプリのアクセス権を取り消すことができ、取り消し後は保存済みのトークンおよび関連データを速やかに破棄します。

6. Google / YouTube ポリシーの遵守

本アプリは YouTube API Services Terms of Service および Google Privacy Policy を遵守します。
